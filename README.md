# AutoDL Grab

简体中文 · [English](README.en.md)

AutoDL Grab 是一个本地运行的 Web 工具，用来在 AutoDL 普通算力市场等候空闲 GPU。勾选一种或多种可接受的型号，选定镜像、同机卡数和整机小时预算，工具会按设定间隔检查市场，直到成功创建一个按量计费实例。

例如，同时勾选 RTX 4090 和 RTX 5090，数量填 2。只要其中一种型号在同一台主机上有两张空闲卡，且镜像和价格符合要求，就可以命中。每轮按市场返回的主机顺序匹配，勾选顺序不代表优先级。

## 在 Windows 上启动

1. 安装 Python 3.11 或更新版本。启动脚本会验证 `python`、`py`，并查找常见的 Python、Miniconda 和 Anaconda 安装路径，自动跳过 Microsoft Store 占位程序。其他安装位置请加入 `PATH`。
2. 下载或克隆项目，在仓库根目录双击 `start.bat`。首次运行会创建虚拟环境并安装依赖。启动脚本会准备所需的浏览器环境。
3. 浏览器会打开[本地工作台](http://127.0.0.1:8765/)。保持启动窗口运行、电脑唤醒。

工作台右上角可切换「中文 / English」。工作台与扩展连接页分别记住语言选择；型号和镜像等平台原始名称保留原文。

## 选择登录方式

| 使用场景 | 操作 | 可用功能 |
| --- | --- | --- |
| 准备自动租用 | 在工作台点「打开 AutoDL 登录」，在专用浏览器窗口登录并保持窗口打开 | 查询、报价、自动创建一个实例 |
| 浏览器中已登录 AutoDL | 用项目附带的扩展连接已登录的 AutoDL 标签页 | 只读查询型号、镜像、库存和报价 |

**通过浏览器扩展连接：** 使用支持 Chromium 扩展的浏览器，打开扩展管理页面，启用「开发者模式」，点「加载已解压的扩展程序」，选择仓库里的 `extension` 文件夹。回到已登录的 `www.autodl.com` 标签页，点击扩展菜单中的「AutoDL Grab 本地连接」。连接页显示「已连接」后，在工作台点击「读取选项」即可查询。使用期间请保持 AutoDL 标签页和扩展连接页打开。

## 从检查匹配到开始抢卡

1. 点「读取选项」，勾选候选显卡，再选择一个基础镜像或账号私有镜像。选定的镜像至少要对一种候选型号可用，实际匹配时还会检查主机架构与驱动。
2. 同机显卡数默认 1。重试间隔默认 30 秒，可输入正整数秒。整机每小时上限可留空；填写后按所需卡数的一小时折扣前报价筛选，因此部分会员折后符合预算的主机会被跳过。最终费用由 AutoDL 结算。
3. 点「检查匹配」可查看当前命中的型号、主机和整机小时报价。**在专用浏览器模式下，点击「开始抢卡」即授权实际创建付费实例。** 抢到后到 AutoDL「我的实例」使用实例，结束使用时自行关机。
4. 首轮立即执行，之后从每轮结束时开始倒计时。运行中点击「保存重试间隔」即可修改：等待时从保存时刻重新计时，检查中从下一轮等待生效。关闭工作台标签页后，后台服务继续运行。

## 中断与订单核对

- 一次运行一个任务。库存被占用时继续等待，登录失效或需要验证时暂停，可在专用浏览器处理后点击「继续任务」。
- 提交前将唯一的 `grab-…` 实例名写入 SQLite。若响应丢失或提交期间服务重启，程序按名称查询「我的实例」。状态为「待核对」时不会再次下单。
- 可点「再次核对」刷新结果。只有在控制台确认没有创建实例时，才用「手动核对」结束任务。停止任务不会关闭或释放已租用的实例。
- 浏览器配置和任务数据库保存在 `.local/`，已加入 Git 忽略规则。服务仅监听本机回环地址。普通市场网页接口可能随平台更新而变化。

## 开发与测试

后端使用 FastAPI、Playwright 和 SQLite，前端使用原生 JavaScript。市场适配在 `market.py`，任务状态和重试逻辑在 `engine.py`。在已运行过启动脚本的项目目录执行：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
node --test tests/test_i18n.js
```

测试使用模拟市场，覆盖多型号候选、同机卡数、价格和镜像约束、间隔修改、停止、订单超时恢复，以及扩展的只读限制。
